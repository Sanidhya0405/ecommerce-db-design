# E-Commerce Database Design Using MySQL

## Overview

This project focuses on designing and implementing a relational database for an e-commerce website using MySQL.

The database is designed to manage core e-commerce operations including customers, sellers, products, orders, order items, payments, and related transactional information.

The project demonstrates practical database design concepts such as normalization, primary and foreign keys, constraints, relationships, joins, aggregate functions, subqueries, views, stored procedures, and analytical SQL queries.

## Objectives

- Design a scalable relational database for an e-commerce platform
- Establish relationships between different business entities
- Maintain data integrity using keys and constraints
- Reduce data redundancy through normalization
- Write efficient SQL queries for business analysis
- Implement stored procedures and views for reusable operations
- Analyze customer, product, seller, and order data
